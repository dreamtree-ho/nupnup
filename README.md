# noop noop

예쁜 순간으로 끝나지 않는, 기분 좋은 밤을 만드는 홈웨어 브랜드 **noop noop**의 공식 웹사이트입니다.

## 구성

- 순수 HTML / CSS / JavaScript
- 별도의 빌드 과정 없음
- 모바일 반응형 레이아웃
- 홈, 브랜드 소개, 제품, 이야기, 연락하기

## 로컬에서 보기

제품 데이터는 브라우저의 `fetch` 기능으로 불러오므로 로컬 서버를 사용해 확인합니다. 저장소 최상위에서 다음 명령을 실행하세요.

```bash
python -m http.server 8000
```

그 후 `http://localhost:8000`에서 확인할 수 있습니다.

## 콘텐츠 수정

제품은 `products.json`에서 관리합니다. `products` 배열에 아래 네 항목을 가진 제품을 추가하면 홈의 대표 제품과 전체 제품 페이지에 자동으로 반영됩니다.

- `name`: 제품명
- `price`: 숫자로 입력한 가격 (미정이면 `null`)
- `image`: 제품 이미지 주소
- `url`: 구매 페이지 주소 (미정이면 `null`)

홈에는 배열의 첫 3개 제품이 표시됩니다. 연락처와 그 밖의 문구는 각 HTML 파일에서 수정할 수 있습니다.

이야기는 `story/posts.json`에서 관리합니다. 새 글을 배열에 추가하면 `story/` 목록과 홈의 최신 이야기 3개에 날짜 내림차순으로 자동 반영됩니다. 글 상세는 `story/post.html?id=글-id` 형식으로 열립니다.
