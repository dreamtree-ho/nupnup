# noop noop

예쁜 순간으로 끝나지 않는, 기분 좋은 밤을 만드는 홈웨어 브랜드 **noop noop**의 공식 웹사이트입니다.

## 구성

- 순수 HTML / CSS / JavaScript
- 별도의 빌드 과정 없음
- 모바일 반응형 레이아웃
- 홈, 브랜드 소개, 제품, 이야기, 연락하기

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 로컬 서버를 사용하려면 저장소 최상위에서 다음 명령을 실행하세요.

```bash
python -m http.server 8000
```

그 후 `http://localhost:8000`에서 확인할 수 있습니다.

## 콘텐츠 수정

임시로 작성된 제품 정보와 연락처는 `index.html`에서 실제 정보로 바꿀 수 있습니다.
